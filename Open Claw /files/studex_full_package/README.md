## GitHub Pages Setup (5 steps)

1. github.com → New repository → Name: `studex-oracle` → Public → Create
2. Add file → Upload files → drag ALL files in this folder
3. Settings → Pages → Branch: main → / (root) → Save
4. Live in 1–2 minutes at: `https://[your-username].github.io/studex-oracle`

## Your Live URLs After Hosting

- Platform: `https://[username].github.io/studex-oracle/`
- NLMK Oracle: `https://[username].github.io/studex-oracle/nlmk_oracle.html`
- Pulsar Oracle: `https://[username].github.io/studex-oracle/pulsar_oracle.html`

## Using the Platform

1. Open `index.html` in browser or visit hosted URL
2. Click "GENERATE REPORT" tab
3. Enter your Anthropic API key (get free at console.anthropic.com)
4. Paste any company's info → Click Generate
5. AI creates 20 questions (10 each direction) in ~60 seconds
6. Download as HTML → Upload to GitHub → Instant new live page
